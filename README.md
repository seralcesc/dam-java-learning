Repositorio de aprendizaje donde documento ejercicios, prácticas y pequeños proyectos desarrollados con **Java** durante mi formación en el Ciclo Formativo de Grado Superior de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

El objetivo del repositorio es mantener un registro organizado de los conceptos trabajados y reflejar mi evolución progresiva como desarrollador.

---

## Objetivos

- Consolidar los fundamentos de programación con Java.
- Desarrollar progresivamente conocimientos de programación orientada a objetos.
- Aplicar los conceptos mediante ejercicios y prácticas.
- Mejorar la organización, legibilidad y mantenibilidad del código.
- Documentar mi evolución durante el aprendizaje.
- Utilizar Git y GitHub como parte habitual del flujo de trabajo.

## Organización

Los ejercicios se agrupan por conceptos para mantener una progresión clara del aprendizaje.

Los ejercicios sencillos pueden contener una única clase, mientras que las prácticas más avanzadas incorporarán progresivamente varias clases, paquetes y estructuras más completas.

### Ejemplo

```text
06-poo/
│
├── 01-clases-y-objetos/
│
├── 02-encapsulacion/
│
└── 03-gestion-biblioteca/
    ├── Main.java
    ├── Libro.java
    ├── Usuario.java
    └── Biblioteca.java
```
